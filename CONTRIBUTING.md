# Contributing

Found a bug? Want to add a feature? Pull requests welcome.

## Local setup

1. Fork & clone
2. `npm install`
3. `npm run dev`
4. Break things, fix things, submit PR

## Code style

- Keep it simple. If you're writing a utility function used once, just inline it.
- Comments explain WHY, not WHAT.
- Prettier handles formatting: `npm run format`

## Before submitting

- `npm run build` should pass
- Test the game flow manually - start a game, mark some cards, check spy master view
